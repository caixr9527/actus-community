### 五条边界复核

1. **常用方式复用 SDK。** 使用 SDK 默认授权码交换与刷新链路、静态客户端材料和
   `QueryKey` 请求认证，只替换百度不同的授权参数、令牌请求和响应解析。
   没有复制 SDK 的事务和存储逻辑。
2. **差异通过公开接口实现。** GET 令牌请求、逗号 scope、缺少 `token_type` 的解析均在
   应用 `OAuthProtocol` 中完成；刷新复用同一组步骤。未配置远端撤销，明确返回未尝试，
   不假装百度授权已经撤销。
3. **公共安全边界保留。** 通过 SDK 平台签名验证事务与连接归属；验证了跨用户拒绝、
   错误 state、重复回调、刷新串行化和加密存储。业务结果仅投影声明字段，日志不包含测试
   client secret、code、访问令牌或刷新令牌。未知写入结果不会自动重试或自动删除远端文件。
4. **自定义链路可交付。** 使用发布版 SDK 完成声明检查、构建、安装、包校验及运行，
   自定义 OAuth 没有被声明或运行校验拦截；安装后应用和 SDK 均从 consumer 的
   `site-packages` 加载，不依赖其他工程源码或私有接口。
5. **文件协议由应用决定。** 暂存、MD5、分片、补传、合并、下载重定向与 EOF 校验在应用内。
   SDK 只负责 `FileInput`／`FileOutput` 交接和公共资源生命周期。JSON 使用 SDK HTTP
   便利接口，分片和下载使用应用自己的 HTTPX 路径，均贯穿原始截止时间。

### 复核修正

除测试结果外，逐项对照旧实现、公开 SDK 契约、百度官方协议代码、产物及文档，完成以下修正：

- 合并始终提交完整有序分片摘要；覆盖部分复用、无缺失分片和乱序缺失分片。
- 秒传缺少文件 ID 时返回空值，不用请求路径生成虚假 ID。
- 下载生成器不跨 `yield` 保留任务上下文或超时管理器，支持不同清理任务关闭。
- 初始 PCS 下载链接携带本次 Token，跨域跳转移除 Token，拒绝未知域名、端口及不完整文件。
- 目录空 MD5 表达为未提供，保留语义结果的 `parent_path`。
- 暂存线程完成后才传播取消；重复取消不提前关闭其文件。清理失败留有固定诊断，保留主要错误。
- 上传排队计入原始截止时间，等待期间不分配第二份暂存文件。
- 厂商缺少容量到期或搜索结束标记时返回未知值，不默认为未到期或已结束。
- 本次复核修正刷新错误分类：503／429 响应中的 `invalid_client` 不能被当成确定的
  客户端拒绝，避免 SDK 将可能已消费的旧刷新凭据继续保持可用；400 的确定客户端拒绝
  仍保留原行为。新增回归先复现两项失败，修正后 81 项测试及独立交付链路通过。

上述可复现问题先补失败回归，再完成修正；最终源码及最终交付包均重新验证。
